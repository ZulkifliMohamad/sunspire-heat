Sunspire Heat is an open-world crime game set in the sun-soaked city of Sunspire: explore on foot and by car, steal vehicles, outrun the police as your wanted level rises, and run missions across the city.

## Run

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## Layout

- `game/` — the game (index.html + src modules + vendored Three.js)
- `screenshots/` — staged screenshots of the game
- `main.ts` — builds the make.fun dossier into the output directory
- `serve.ts` — dev static server for `game/`
- `vendor/makefun-game.ts` — kit dossier library (unchanged)
